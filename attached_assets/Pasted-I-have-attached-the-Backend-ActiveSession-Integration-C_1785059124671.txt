## 3. Create Driver ActiveSession Context

Create a centralized provider similar in responsibility to the Passenger ActiveSession implementation.

It should expose:

- session
- loading
- error
- initialized
- initializeActiveSession()
- refreshActiveSession()
- clearActiveSession()

Behavior:

Initialization:
- call GET /api/driver/session
- data object → store session
- data null → clear session
- request failure → keep previous session and expose error
